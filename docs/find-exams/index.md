# Encontre suas provas

No USPolis as provas são divididas em provas de disciplinas sem turmas específicas ou provas onde as turmas são especificadas, ao acessar a página "Encontre suas provas" você vai ver:

## Como ver provas antigas

Por padrão, a página só mostra provas que **ainda não passaram**. Clicando no ícone de interrogação ao lado do título, você vê esse lembrete:

<div style="
  display: flex;
  justify-content: center;
  align-items: center;
  width: 100%;
">
  <img 
    src="/find-exams/image-4.png"
    alt="Descrição"
    style="
      border-radius: 8px;
      max-width: 100%;
      height: auto;
      box-shadow: 0 4px 16px rgba(0,0,0,0.1);
    "
  />
</div>

Para ver uma prova que já aconteceu, clique no indicador **"Período: Atual"** e informe outro intervalo:

<div style="
  display: flex;
  justify-content: center;
  align-items: center;
  width: 100%;
">
  <img 
    src="/find-exams/image-5.png"
    alt="Descrição"
    style="
      border-radius: 8px;
      max-width: 100%;
      height: auto;
      box-shadow: 0 4px 16px rgba(0,0,0,0.1);
    "
  />
</div>

Basta inserir o **Início** e **Fim** do período que deseja buscar e clicar em **Confirmar** — esse período deve conter **todas as datas de uma reserva do tipo "Prova"** que você quer encontrar. Por exemplo, suponha que para MAC2166 existia uma reserva do tipo "Provas" com as datas: 24/04/25 (P1) e 26/06/25 (P2), então o seu intervalo deve conter ambas as datas para que ela apareça no site. Use **Desfazer** para voltar ao período atual.
