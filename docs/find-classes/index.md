# Encontre suas aulas

Você pode encontrar suas aulas através da página "Encontre suas aulas", que pode ser acessada pelo menu lateral. Ao entrar na página, se você ainda não escolheu nenhuma disciplina, ela já mostra uma lista de **"Próximas disciplinas"** — as turmas com aula mais próxima de acontecer:

<div style="
  display: flex;
  justify-content: center;
  align-items: center;
  width: 100%;
">
  <img

    alt="Descrição"
    style="
      border-radius: 8px;
      max-width: 100%;
      height: auto;
      box-shadow: 0 4px 16px rgba(0,0,0,0.1);
    "
  />

Cada cartão de turma já mostra a disciplina, o(s) professor(es) (marcado com um ícone os que são responsáveis pela disciplina), os horários e locais de todas as suas aulas na semana, e uma etiqueta com o status em relação a agora — **CHEGANDO**, **EM ANDAMENTO**, **SEM AULA HOJE** ou **ENCERRADA**.

## Buscando uma disciplina específica

Você pode encontrar uma disciplina específica pelo seletor **Disciplina**:

<div style="
  display: flex;
  justify-content: center;
  align-items: center;
  width: 100%;
">
  <img 
    src="/find-classes/image-1.png"
    alt="Descrição"
    style="
      border-radius: 8px;
      max-width: 100%;
      height: auto;
      box-shadow: 0 4px 16px rgba(0,0,0,0.1);
    "
  />
</div>

Ao selecionar uma disciplina, o seletor **Turma** é liberado e a seção **"Turmas:"** passa a mostrar todas as turmas daquela disciplina, cada uma já com professor, horários, sala e o status atual:

<div style="
  display: flex;
  justify-content: center;
  align-items: center;
  width: 100%;
">
  <img 
    src="/find-classes/image-2.png"
    alt="Descrição"
    style="
      border-radius: 8px;
      max-width: 100%;
      height: auto;
      box-shadow: 0 4px 16px rgba(0,0,0,0.1);
    "
  />
</div>

Use o seletor **Turma** para filtrar e ver apenas uma turma específica em vez de todas de uma vez.

Dessa forma você consegue encontrar qualquer disciplina e turma cadastrada no nosso sistema. Se você não encontrou alguma disciplina entre em contato conosco por **uspolis@usp.br**.
